
# Zig-Zag SpA — Soluciones Gráficas (Web Design)
# Estado: Inactivo

Reconstrucción moderna, limpia y optimizada de la plataforma web corporativa **Zig-Zag SpA**.
Servicios de imprenta y soluciones gráficas integradas.

## 🚀 Tecnologías Utilizadas

Este proyecto prescinde de frameworks complejos de JavaScript, apostando por un rendimiento óptimo y una arquitectura modular basada en estándares web:

* **HTML5 Semantic:** Estructura clara y accesible orientada a SEO.
* **CSS3 Custom Properties (`styles.css`):** Variables de diseño, sistema de colores de marca y animaciones personalizadas de *scroll reveal*.
* **JavaScript Vanilla (`main.js`):** Lógica desacoplada para la renderización dinámica de categorías, servicios, interactividad de pestañas y gestión del formulario de contacto.
* **Lucide Icons:** Iconografía moderna y ligera.

## Características Principales

*  **Diseño Responsive:** Adaptado perfectamente a dispositivos móviles, tablets y escritorios.

* **Navegación Dinámica:** Catálogo interactivo de servicios divididos en 5 áreas clave (Identidad de Marca, Diseño Publicitario, Editorial, Gran Formato y Diseño Digital).

* **Animaciones de Entrada:** Efectos visuales de aparición progresiva al hacer scroll (Intersection Observer).

* **Formulario de Contacto Interactivo:** Simulación de envío con validación y confirmación visual instantánea.
